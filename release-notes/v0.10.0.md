## BlaulichtCMS 0.10.0

Update **ohne neues Docker-Image**: Im Warnentwurf lässt sich das betroffene Gebiet auf einer Karte markieren, das PDF
zeigt dazu einen Kartenausschnitt. Facebook- und Instagram-Verbindungen bekommen den Schalter „Nur lesen“, und das
Update-Protokoll erklärt jetzt verständlich, was jede Version gebracht hat.

Keine Datenbank-Migration; Daten, Konten, Rollen und gekoppelte Websites bleiben unverändert.

### Warnentwurf: Gebiet auf der Karte

- Im Schritt **Gebiet & Zeitraum** gibt es unter der Beschreibung eine Karte (OpenStreetMap): **Gebiet einzeichnen**,
  die Eckpunkte anklicken, **Fertig**. Die Karte merkt sich den letzten Ausschnitt.
- Das markierte Gebiet gehört zur Fassung – eine Änderung braucht wie jeder Inhalt eine neue Freigabe.
- Im **PDF** steht unter „Betroffenes Gebiet“ ein Kartenausschnitt mit der roten Markierung. Maßgeblich bleibt die
  Beschreibung im Textfeld.
- Die Kartenkacheln lädt BlaulichtCMS über den eigenen Server – der Browser baut keine Verbindung zu OpenStreetMap auf.

### Facebook und Instagram: „Nur lesen“

- Neuer Schalter **„Nur lesen (Veröffentlichen sperren)“** in der Verbindung: Reichweite, Seitenstatistik und
  Social-Feed laufen weiter, aber BlaulichtCMS veröffentlicht, löscht und testet nichts über diese Verbindung.
- Die Sperre gilt auf dem Server an jeder Stelle (Beitrag, Workflows, Veröffentlichen, Entfernen, Verbindungstest).
- Einschalten wirkt sofort ohne neuen Test; Ausschalten verlangt einen neuen Test.

### Update-Protokoll mit Versionshinweisen

- Unter *Verwaltung → Einstellungen → Updates & Wartung* zeigt das Protokoll je Update unter **„Was ist neu“** kurz,
  was die Version gebracht hat – aufklappbar mit allen Neuerungen. Die technische Meldung steht klein darunter.
- Das gilt auch für die bisherigen Updates.

### So spielst du das Update ein

Unter *Verwaltung → Einstellungen → Updates & Wartung* das Update auf **0.10.0** mit dem **Update-Knopf** einspielen
(Recht „Updates einstellen und installieren“, Bestätigung mit Passwort und Zwei-Faktor-Code). BlaulichtCMS sichert
vorher alles und ist während des Wechsels kurz nicht erreichbar.

**Von 0.7.x aus:** Erst auf 0.8.0 gehen (neues Docker-Image) – siehe
[Versionshinweise 0.8.0](https://github.com/thisislennard/BlaulichtCMS/blob/v0.8.0/release-notes/v0.8.0.md).

### Nach dem Update

- **Version prüfen:** *Verwaltung → Einstellungen → Updates & Wartung* zeigt **0.10.0**.
- **Karte:** Beim ersten Öffnen lädt der Server die Kartenkacheln von OpenStreetMap; BlaulichtCMS braucht dafür
  ausgehenden Internetzugang (wie für Facebook und Instagram).
