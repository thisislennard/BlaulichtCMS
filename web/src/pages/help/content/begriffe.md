Jedes Wort hat in BlaulichtCMS genau eine Bedeutung. So heißen die Dinge in Menü, Seiten, Benachrichtigungen und dieser Hilfe.

## Veröffentlichen

| Begriff | Bedeutung |
|---|---|
| **Website** | Eine über die BlaulichtCMS Bridge gekoppelte WordPress-Website. Im Beitrag das Ziel „Veröffentlichen auf“. Eingerichtet unter [Einrichtung → Websites](/websites). |
| **Soziale Netzwerke** | Facebook, Instagram, Threads, X, Mastodon, Bluesky und der WhatsApp-Kanal (so heißt der Dienst bei WhatsApp). |
| **Veröffentlichungsziele** | Website und soziale Netzwerke zusammen. Sie sind Teil der Fassung. |
| **Update-Stufe** | „Test“ oder „Stabil“ je Website: In der Stufe „Test“ kommen neue Bridge-Versionen zuerst an. |
| **Bridge** | Das WordPress-Plugin „BlaulichtCMS Bridge“, das freigegebene Aufträge abholt. |
| **Kopplungscode** | Einmaliger Code, mit dem eine Website einen eigenen Schlüssel erhält. |
| **Veröffentlichungsauftrag** | Auftrag an eine Website für genau eine freigegebene Fassung. |

## Beiträge und Freigabe

| Begriff | Bedeutung |
|---|---|
| **Fassung** | Unveränderlicher Stand eines Beitrags (oder eines Eintrags der Einsatzliste); jede Änderung erzeugt eine neue. In Listen kurz `F2`, neben Einsatzstichwörtern ausgeschrieben „Fassung 2“. |
| **Freigabe** | Entscheidung für genau eine Fassung (mit Prüfsumme). |
| **Prüfsumme** | Fingerabdruck über Text, Medien und Veröffentlichungsziele einer Fassung. |
| **Beitragsvorlage** | Vorlage für wiederkehrende Beiträge, z. B. Einsatzbericht – unter [Einrichtung → Beitragsvorlagen](/beitragsvorlagen). |
| **Textbaustein** | Wiederkehrende Formulierung für Antworten auf Presseanfragen – unter [Presse → Textbausteine](/presse/textbausteine). |

## Fotos und Videos

| Begriff | Bedeutung |
|---|---|
| **Fotos sammeln** | Die Aktion (im Dashboard, im Beitrag, in der Suche), die eine Sammlung samt Upload-Link anlegt. |
| **Sammlung** | Ablage für Fotos und Videos – eigenständig oder zu einem Beitrag, unterteilbar in Ordner. |
| **Upload-Link** | Befristeter, widerrufbarer Link zum Hochladen ohne Konto in genau eine Sammlung. |
| **Upload-Seite** | Die öffentliche Seite hinter einem Upload-Link. Ihr Standard-Aussehen steht unter [Einrichtung → Upload-Seite](/upload-seite). |
| **Aushang** | Druckansicht (A4) eines Upload-Links mit QR-Code. |
| **Eingang** | Zeitpunkt, zu dem eine Datei hochgeladen wurde – allgemein: etwas ist eingegangen (Mail im Presse-Postfach, Einsatzmeldung über den FE2-Eingang, „Eingang bestätigt“ beim Warnentwurf). |
| **Quarantäne** | Private Ablage für neue Uploads bis zur Prüfung. |
| **Sichtung** | Auswählen oder Überspringen von Dateien. |
| **Original** / **Öffentliche Fassung** | Unveränderte hochgeladene Datei (nur intern) bzw. die Datei ohne Standort- und Kameradaten für Veröffentlichungen. |

## Vorlagen

„Vorlage“ steht nie allein, sondern immer mit dem, wofür sie ist:

| Begriff | Bedeutung |
|---|---|
| **Beitragsvorlage** | Titel, Art und Text für wiederkehrende Beiträge. |
| **Designvorlage** | Datei der internen Bibliothek: Logo, Layout, Plakat, Schrift – unter [Redaktion → Designvorlagen](/designvorlagen). |
| **Bildvorlage** | Befüllbare Designvorlage, aus der BlaulichtCMS Bilder erzeugt (z. B. Sharepics). |
| **Übergabe-Vorlage** | Aufbau der Übergabe eines Warnentwurfs an die zuständige Stelle (unter Stichwörter & Regeln). |
| **Workflow-Vorlage** | Fertiger Ablauf, mit dem ein neuer Workflow beginnt. |
| **Dashboard-Vorlage** | Anordnung des Dashboards für alle oder eine Rolle. |
| **Mustertext** | Startpunkt zum Anpassen, z. B. für die Datenschutzerklärung oder eine KI-Anfrage. |

## Verbindungen und Workflows

| Begriff | Bedeutung |
|---|---|
| **Verbindung** | Kopplung mit einem externen Dienst – eingehend (FE2, Feuersoftware Connect, amtliche Warnungen) oder zum Veröffentlichen (soziale Netzwerke). Unter [Einrichtung → Verbindungen](/verbindungen). |
| **Auslöser** | Workflow-Baustein, der einen Lauf startet: Alarm, amtliche Warnung, RSS-Eintrag, Uploads, Termin, Presseanfrage, Zeitplan oder Start von Hand. |
| **Aktion** | Workflow-Baustein, der etwas tut: Banner, Beitrag, E-Mail, App-Benachrichtigung, Warnentwurf, Eintrag in der Einsatzliste, Pressemitteilung. |
| **Zweig** | Anschluss eines Knotens im Workflow-Editor, z. B. „trifft zu“ oder „freigegeben“. |
| **Stichwort** | Einsatzstichwort wie „F 1“ oder „B 2“ samt Aliasen (unter Stichwörter & Regeln). |
| **Einsatzmeldung** | Meldung über einen Einsatz aus FE2 oder Feuersoftware Connect – nur intern, mit Empfangsprotokoll. |
| **Einsatzentwurf** | Aus einer Einsatzmeldung vorgeschlagener interner Beitragsentwurf. |
| **Einsatzliste** | Öffentliche Liste vergangener Einsätze auf der Website, mit eigener Freigabe – unter [Redaktion → Einsatzliste](/einsatzliste). |

## Kalender

| Begriff | Bedeutung |
|---|---|
| **Externe Kalender einlesen** | Termine aus anderen Programmen (iCal-Link, z. B. Outlook oder Google) in den Kalender übernehmen. |
| **Kalender abonnieren** | Den BlaulichtCMS-Kalender über einen geheimen Abo-Link in Outlook, Google oder auf dem Handy anzeigen. |
