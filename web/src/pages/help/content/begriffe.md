| Begriff | Bedeutung |
|---|---|
| **Aushang** | Druckansicht (A4) eines Links mit QR-Code |
| **Bridge** | Das WordPress-Plugin „LifeLink Bridge“, das Aufträge abholt |
| **Fassung** | Unveränderlicher Stand eines Beitrags; jede Änderung erzeugt eine neue |
| **Freigabe** | Entscheidung für genau eine Fassung (mit Prüfsumme) |
| **Kopplungscode** | Einmaliger Code, mit dem eine Website einen eigenen Schlüssel erhält |
| **Öffentliche Fassung** | Mediendatei ohne Standort- und Kameradaten, für Veröffentlichungen |
| **Original** | Unveränderte hochgeladene Datei, nur intern |
| **Prüfsumme** | Fingerabdruck über Text, Medien und Zielkanal einer Fassung |
| **Quarantäne** | Private Ablage für neue Uploads bis zur Prüfung |
| **Sammlung** | Ordner für Fotos und Videos, eigenständig oder zu einem Beitrag |
| **Sichtung** | Auswählen oder Überspringen von Dateien |
| **Upload-Link** | Befristeter, widerrufbarer Link zum Hochladen ohne Konto |
| **Veröffentlichungsauftrag** | Auftrag an eine Website für genau eine freigegebene Fassung |
| **Zielkanal** | Wohin veröffentlicht wird (z. B. WordPress-Website) |
