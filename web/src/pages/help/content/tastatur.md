Mit der Tastatur geht vieles schneller. Auf dem Mac gilt `kbd:⌘` statt `kbd:Strg`.

## Überall

| Kürzel | Aktion |
|---|---|
| `kbd:Strg+K` | Globale Suche und Befehlspalette: Workflows, Schnittstellen, Läufe und Seiten finden |
| `kbd:↑` / `kbd:↓`, `kbd:Enter` | In Listen und Menüs wählen und öffnen |
| `kbd:Esc` | Dialog, Menü, Popover oder Panel schließen |
| `kbd:Tab` / `kbd:Umschalt+Tab` | Zum nächsten / vorherigen Bedienelement |
| `kbd:←` / `kbd:→` | Zwischen Reitern wechseln, wenn ein Reiter fokussiert ist |

Ganz oben auf jeder Seite gibt es den unsichtbaren Link „Zum Inhalt springen“ – er erscheint mit dem ersten `kbd:Tab`.

## Dashboard

Die Schnellaktionen auf dem Dashboard haben eigene Tasten (nur, wenn gerade kein Eingabefeld aktiv ist):

| Taste | Aktion |
|---|---|
| `kbd:N` | Neuen Workflow erstellen |
| `kbd:I` | Schnittstelle verbinden |
| `kbd:T` | Testlauf starten (Workflow wählen) |
| `kbd:L` | Läufe ansehen |

Welche Aktionen erscheinen, hängt von euren Rechten ab.

## Workflow-Editor

| Kürzel | Aktion |
|---|---|
| `kbd:/` | In die Baustein-Suche der Palette springen |
| `kbd:Strg+Z` | Rückgängig |
| `kbd:Strg+Umschalt+Z` oder `kbd:Strg+Y` | Wiederholen |
| `kbd:Strg+C` | Ausgewählte Bausteine kopieren |
| `kbd:Strg+V` | Kopierte Bausteine einfügen (ein kopierter Trigger wird ausgelassen) |
| `kbd:Entf` oder `kbd:Rücktaste` | Ausgewählte Bausteine oder Linien löschen |
| `kbd:Umschalt` + Klick | Mehrere Bausteine auswählen |
| `kbd:Umschalt` + Ziehen | Auswahlrahmen aufziehen |
| `kbd:Esc` | Auswahl aufheben bzw. Einstellungen schließen |
| `kbd:Enter` in der Palette | Gewählten Baustein einfügen |

Gelöschte Bausteine lassen sich mit `kbd:Strg+Z` zurückholen.

## Variablen-Picker

| Kürzel | Aktion |
|---|---|
| `kbd:↑` / `kbd:↓` | Variable wählen |
| `kbd:Enter` | Variable einfügen |
| `kbd:Esc` | Picker schließen |

## Hilfe

| Kürzel | Aktion |
|---|---|
| `kbd:/` | In die Hilfesuche springen |
| `kbd:↑` / `kbd:↓`, `kbd:Enter` | Treffer wählen und öffnen |
| `kbd:Esc` | Suche leeren bzw. schließen |
