## Erste Anmeldung über eine Einladung

Ein Admin lädt dich unter **Benutzer und Rollen** ein. Du bekommst einen persönlichen Link, zum Beispiel per Messenger oder E-Mail.

- Der Link ist **einmalig**: Nach dem Festlegen des Passworts funktioniert er nicht mehr.
- Er ist **befristet** (Standard 72 Stunden) und kann vom Admin **widerrufen** werden.
- Abgelaufen? Ein Admin erzeugt in der Benutzerliste über „Neuer Einladungslink“ einen neuen.

## Passwort

Mindestens 12 Zeichen. Ein langer Satz ist gut merkbar und sicher, z. B. `Morgens zwei Kaffee, abends drei Tee`. Bekannte Wörter allein reichen nicht.

## Zwei-Faktor-Anmeldung

Für Administratoren ist ein zweiter Faktor Pflicht (abschaltbar unter Einstellungen → Sicherheit). Du brauchst eine Authenticator-App (z. B. Aegis, 2FAS, Google oder Microsoft Authenticator):

1. QR-Code scannen.
2. Den 6-stelligen Code eingeben.
3. Die **Wiederherstellungscodes** sicher aufbewahren. Jeder funktioniert genau einmal, falls das Telefon verloren geht.

## Gesperrt?

Nach fünf falschen Passwörtern ist das Konto 15 Minuten gesperrt. Ein Admin kann in der Benutzerliste einen Link zum Neusetzen des Passworts erzeugen oder die Zwei-Faktor-Anmeldung zurücksetzen. Notfallbefehle für den Server stehen unter [Fehlerbehebung](/hilfe/fehlerbehebung).
